Kamel Money is a free, fast and transparent web app that helps the diaspora save money. It compares **live fees and exchange rates from 7 major money transfer providers**: **Wise, Remitly, Revolut, WorldRemit, Ria, MoneyGram, and Western Union**.

No registration. 100% free.

### ✨ Features
- **Real-time comparison**: Live mid-market FX rates updated hourly via ER-API
- **7 providers**: Wise, Remitly, Revolut, WorldRemit, Ria, MoneyGram, Western Union
- **Smart calculator**: Shows exact fee, FX margin, delivery speed and final amount received
- **4 languages**: Czech (default), English, French, German - auto saved with localStorage
- **No registration**: No account, no tracking. All calculations in browser
- **Mobile-first & PWA**: Installable, works offline, 460px max-width app shell
- **Transparent & Independent**: Cheapest first. Affiliate disclosure included

- **PWA:** Service Worker, manifest, offline-ready, Add to Home Screen
