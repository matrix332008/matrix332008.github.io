# 🐪 Kamel Money

**Compare remittance fees & FX rates instantly.** Save money when sending to Tunisia, Morocco, Algeria, Egypt, and more.

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://kamel-money.com)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

### 🚀 Live Demo
**https://kamel-money.com**

Kamel Money is a free web app that compares live fees and exchange rates from 7 major money transfer providers: **Wise, Remitly, Revolut, WorldRemit, Ria, MoneyGram, and Western Union**.

### ✨ Features
- **Real-time comparison**: Live FX rates updated hourly
- **7 providers**: Compare Wise, Remitly, Revolut, WorldRemit, Ria, MoneyGram, Western Union
- **4 languages**: Czech, English, French, German
- **No registration**: 100% free, no account needed
- **Mobile-first**: Works offline, installable PWA
- **Transparent**: Shows exact fees, FX margins, and final received amount

### 🌍 Supported Countries
**Send from**: Czech Republic, Poland, Germany, France, Italy, Spain, Netherlands, Belgium, UK, Canada, US, UAE  
**Send to**: Tunisia, Morocco, Algeria, Egypt, Jordan, Lebanon, Turkey, India, Pakistan, Bangladesh, Philippines, Nigeria

### 🛠️ Tech Stack
- **Frontend**: Vanilla HTML, CSS, JavaScript - no frameworks
- **FX Rates**: Live mid-market rates via ER-API
- **Hosting**: GitHub Pages
- **PWA**: Installable, works offline

### 📄 Pages
- `index.html` - Main comparison calculator
- `about.html` - About our mission
- `privacy.html` - Privacy policy & AdSense compliance  
- `contact.html` - Contact information
- `settings.html` - Language & number format settings
